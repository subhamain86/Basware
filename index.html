Welcome — what does this tool do?

AP-SQL Assistant · Version 10.3

This assistant writes database queries for you — both read-only reports and Change Request SQL (INSERT / UPDATE / DELETE text) — using the organization's approved database schema as its single source of truth, and helps you correct a SQL query when a database gives you back an error. You can build a query either by describing what you need in plain language, by making selections manually, or both together. Schema updates can also now be synced across browsers, devices, and users — either by linking a shared file (Chrome/Edge), or via GitHub itself, which works in every browser and is ideal when this app is hosted on GitHub Pages. It never connects to a real database and never executes anything; it only ever produces SQL text for you to review and copy.

Cross-Device Schema Sync Option A

Link the active schema to a single shared file — placed in a SharePoint document library, a synced OneDrive folder, or a shared network drive. This requires a Chromium-based browser (Chrome, Edge, or similar).

AP-SQL Assistant only reads and writes that one file through your browser's own permission system.

GitHub-Hosted Schema Sync Option B — New in V10.3

Sync the active schema through a JSON file stored in a GitHub repository, using GitHub's own REST API. Unlike Option A, this works in every browser (Chrome, Edge, Firefox, Safari) — a natural fit since this application itself can be hosted on GitHub Pages.

Your Personal Access Token is stored only in this browser's local storage and sent only to api.github.com over HTTPS — it is never sent anywhere else. Use a fine-grained token scoped only to this one repository with Contents: Read and write permission, so that even if this browser/profile were compromised, the exposure is limited to that single repo.

Everyone who needs the same schema should point at the exact same owner/repo/path/branch. Create the token at github.com/settings/tokens (fine-grained, recommended) or github.com/settings/tokens/new (classic, "repo" scope).
